# Journal-grade evaluation harness

Re-runnable scripts that produce every quantitative cell in the
`Quantitative Cross-System Comparison` subsection of the companion
manuscript (which lives in a separate repository — see the project
README for the link). LaTeX fragments are emitted into
`bench/eval/figs/`; the manuscript ``\input{}``s them from there.

| metric | script                                  | API cost    |
|--------|-----------------------------------------|-------------|
| M1     | `m1_extraction.py`                      | $0          |
| M2     | `m2_determinism.py`                     | ≤ $0.50 (Haiku 4.5)  |
| M3     | piggy-backs on M2 (timestamps)          | $0 marginal |
| M4     | `m4_judge.py`                           | ≤ $0.50 (Sonnet 4.6) |

Total wall-clock for a full re-run: ≈ 4 minutes.
Total API spend recorded in `results/cost_ledger.json`.

The judge prompt is pinned verbatim in `rubric.txt`; the ground-truth
clause set in `gold_clauses.json`. Both files are version-controlled and
the LaTeX tables are regenerated by `tables.py` from the JSON in
`results/`. No cell in any table is hand-edited.

## Reproducing
```bash
python bench/eval/m1_extraction.py     # 60-clause extraction accuracy
python bench/eval/m2_determinism.py    # cross-system byte-determinism
python bench/eval/m4_judge.py          # LLM-as-judge diagram quality
python bench/eval/tables.py            # regenerate LaTeX fragments
```

`m2_determinism.py` and `m4_judge.py` shell out to `claude -p
--output-format json` so they require Claude Code (or a wrapper that
exposes the same interface). To run against the raw Anthropic API, set
`ANTHROPIC_API_KEY` and pass `--api` to either script.

Hard cap on cumulative spend: USD 20. Soft target: under USD 1.
