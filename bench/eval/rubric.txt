JOURNAL-EVALUATION JUDGE RUBRIC

You are scoring two SVG diagrams that were each generated from the SAME
natural-language sentence. One diagram comes from System A, the other
from System B. You do NOT know which is which, and you must not infer
it. Score each diagram on four axes, each from 1 to 5 (integer).

Axes
----

1. RELATION FAITHFULNESS — does the visual encoding (line style,
   arrowhead, position, nesting, marker) intuitively suggest the
   verb-relation expressed in the sentence? 1 = wrong relation
   suggested; 3 = ambiguous; 5 = relation is unambiguous from the
   visual alone.

2. CONCEPT COVERAGE — does the diagram name BOTH concepts that the
   sentence mentions, and does it name them clearly (no truncation,
   no extra unrelated concepts, no random text)? 1 = a concept is
   missing; 3 = both present but cluttered; 5 = exactly the two
   concepts, clearly labelled.

3. STRUCTURAL CLARITY — boxes legible, no overlap, no occluded text,
   no off-canvas geometry, sensible spacing? 1 = unreadable; 3 =
   readable but cramped; 5 = clean and well-spaced.

4. RENDER VALIDITY — does the SVG parse as a single self-contained
   <svg>...</svg> document, with no decorative noise (no embedded
   bitmap data, no <foreignObject> escape hatch unless used for
   typeset math, no commented-out alternatives)? 1 = malformed; 3 =
   valid but wasteful; 5 = clean, minimal, valid.

Output protocol
---------------

Return ONLY a single JSON object. No prose, no markdown fences, no
"here is the answer" preamble. The JSON must follow exactly this
schema:

{
  "A": {"relation_faithfulness": <1-5>, "concept_coverage": <1-5>,
        "structural_clarity": <1-5>, "render_validity": <1-5>,
        "comment": "<one sentence>"},
  "B": {"relation_faithfulness": <1-5>, "concept_coverage": <1-5>,
        "structural_clarity": <1-5>, "render_validity": <1-5>,
        "comment": "<one sentence>"}
}

Score each axis independently. Do NOT round the two systems toward
each other. If one diagram is plainly better on an axis, the gap
should appear in the scores.
