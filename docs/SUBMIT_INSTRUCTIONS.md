# How to submit the OpenAI + Anthropic startup applications

## Reality check on what to expect

| | OpenAI | Anthropic |
|---|---|---|
| **Self-serve tier (no VC)** | up to **$2,500** | **$1,000–$5,000** |
| **VC-partner tier** | $15K–$100K | $25K–$100K+ |
| **Review time** | 2–6 weeks | 2–4 weeks |
| **Form length** | short web form | short web form |
| **Public URL** | https://openai.com/startups/ | https://claude.com/programs/startups |

**Both forms are SHORT.** Don't paste the entire .md file into one text box. Copy the relevant section into each field.

## Before you submit

### 1. Decide on the team paragraph
The .md files have two **[TEAM]** versions:
- Single-founder (Arash only)
- Co-founder (Arash + Brother as CTO)

**Pick before submitting.** Co-founder version increases acceptance odds materially.

### 2. Plug in real numbers
The drafts have placeholders:
- `~$200-$400/month` → check the OpenAI dashboard for actual monthly spend
- `XX active prompts/day` → check the admin page (`/admin` on khayyammath.com)

### 3. Decide whether you want the small self-serve tier or a VC referral first
- **Self-serve now**: $2,500 OpenAI + $5K Anthropic = ~$7,500 total credits. Fast (2-4 weeks).
- **Wait for VC referral**: apply via Hub71 (Abu Dhabi) or similar accelerator first. Slower (~2-3 months) but unlocks 5-20× higher tiers.

**Recommendation**: do the self-serve applications NOW for the small tier. Pursue Hub71 in parallel.

## Submission flow

### OpenAI

1. Open `https://openai.com/startups/` in your browser
2. Click the apply / "Get started" CTA
3. Fill these fields from the `.md` file:
   - **Company name** → `Khayyam Math`
   - **Website** → `https://khayyammath.com`
   - **Founder name + email** → your info
   - **Country** → UAE
   - **Product description (short)** → the *"One-paragraph description"* section
   - **How you use OpenAI's API** → the *"How we use OpenAI"* section, condensed
   - **Current usage / spend** → fill in real numbers
   - **Team** → pick one of the **[TEAM]** paragraphs
   - **VC partner referral code** → leave blank (you don't have one yet) OR paste Hub71 if you've already onboarded there
4. Submit.

### Anthropic

1. Open `https://claude.com/programs/startups` in your browser
2. Click the apply CTA (in the Standard / Self-serve track if presented)
3. Similar fields. Key difference in framing:
   - For "How do you use Claude?" → be **honest**: "Not yet integrated; planned integration in 90 days as parallel model + second-opinion correctness inspector. See attached integration plan."
   - The *"Specific integration plan (90 days)"* section in the .md is the most important paragraph for Anthropic — they want to see you'll actually use Claude credits.
4. Attach the PDF (`docs/application_anthropic_startup.pdf`) if a file upload is offered.
5. Submit.

## After submission

- **Track**: keep an email folder for each application
- **Wait**: 2-4 weeks before pinging
- **In parallel**: file Hub71 application (Abu Dhabi) — unlocks higher tiers + regional credibility

## If the forms ask something I haven't covered

Most likely additional fields:
- **Founded date** → use the date Khayyam Math was registered
- **Funding stage** → "Bootstrapped" or "Pre-seed"
- **Employees** → "1 (or 2 if co-founder version)"
- **Industry** → "EdTech / AI Tutoring"
- **Target market** → "K-12 + early undergraduate math, UAE/GCC + Indian competitive exam prep"
- **Expected monthly API spend post-credit** → "$500-$2,000 depending on validation outcome"
- **How did you hear about us** → "Direct" or "Internet research"

These are easy one-liners; don't overthink them.
