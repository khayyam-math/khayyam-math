2026-06-12: user screenshot of "Subset Sum to Partition" showed overlapping/duplicated labels (S1/S2 stamped on the same spot; halves that summed to 9 vs 11, i.e. WRONG arithmetic). Root cause: the prompt "reduce subset sum to partition" has NO "NP-complete" keyword, so `is_np_completeness_prompt` returned False and it fell through the whole cascade to the LLM-SVG fallback, which invents coordinates + arithmetic. The probe never caught it because it only screened bounds/oversize/leaks, not text-on-text overlap. User chose "Both" (deterministic renderer AND geometric safety-net). Three layers shipped (commit 3a916ae, deployed, ECS healthy, pushed):

1. **`studio/templates/reduction.py`** — deterministic reduction renderer. Subset Sum ≤p Partition renders FULLY deterministically (no LLM) from an arithmetic-checked canonical example (S={2,3,4,8}, T=5, added a=|17−10|=7, halves S1={2,3,7}=12 / S2={4,8}=12, asserted equal in code). Other recognised "reduce A to B" pairs get a number-free schematic via `_parse_pair`. Wired in `express.py` right AFTER the np_completeness block (so NP-proof prompts still win), flag `SEVIM_REDUCTION_ROUTE` (default on). Needs no api_key. `tests/test_reduction.py`.

2. **`drop_duplicate_texts(svg)` in `express.py`** — the gap single-channel dedup + nudging leave: an identical label stamped twice at the same spot (nudging two identical strings still shows the dup; must DROP one). Conservative: ≥5 chars, must actually bbox-overlap, keeps far-apart repeats, anchor-aware bbox. Added to `polish_svg` passes AND the LLM pipeline before `reflow_overlapping_text`. `tests/test_drop_duplicate_texts.py`. NOTE pre-existing `reflow_overlapping_text` only nudges TOP-LEVEL text and never drops dups — that's why it didn't fix the screenshot.

3. **Probe overlap check** — `studio/quality_probe.py` `_overlapping_text_pairs()` flags text pairs whose bboxes overlap >50% of the smaller, reusing the transform-resolving DOM walk (`_parse_transform`/`_compose`) so graphviz translate-wrapped output doesn't false-positive; None on irreducible rotation/matrix. Wired into `inspect_quality`. Tests in `tests/test_quality_probe.py`.

488 tests pass. See [[project_quality_probe_2026_06_12]], [[feedback_deterministic_routes_no_fallback]], [[project_taxonomy_system]].
